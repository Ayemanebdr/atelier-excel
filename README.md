# Atelier Excel & Power BI — cas Rhôna Distribution

Application d'apprentissage (PWA) : cours, cas pratiques et corrigés pour le contrôle de gestion, sur un cas d'entreprise fictif qui évolue sur 16 séances.

- `index.html` : l'application
- `content.js` : le programme et le contenu des séances
- `files/` : le classeur Excel de chaque séance (énoncé, données, corrigé)

La progression est enregistrée dans le navigateur ; le bouton « Sauvegarder ma progression » permet de la transférer d'un appareil à l'autre.
